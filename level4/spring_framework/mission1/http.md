# HTTP

## Q. HTTP란 무엇인가?

> 직관 : `하이퍼텍스트`-`초문서?` 전달 통신규약 // 통신의 규약  
> 실증 : 클라이언트-서버 사이 상호 대화를 위한 요청-응답 프로토콜.

## Q. HTTP의 대표적인 특성 3가지는?

> 직관 : 무상태성, 요청과 응답? 아스키 코드? 헤더/본문? 상태 코드?
> 실증 : 클라이언트-서버(요청-응답) 구조, 무상태성, 비연결성

- Application layer
    - 브라우저 등 애플리케이션을 위한 기능 제공
    - 하위 계층(TCP)에 대한 연결 제공
    - 데이터 입/출력 발생
- Client-server model
    - Client
    - _Web_ Server
    - Proxy
- Stateless protocol
    - HTTP is stateless, but not sessionless
- 진짜 웹 서버가 하는 일
    - 클라이언트 커넥션 수락 - 클라이언트의 접속을 연결한다.
    - 요청 메시지 수신 - HTTP 요청 메시지를 네트워크로부터 읽는다.
    - 요청 처리 - 요청 메시지를 읽고 처리한다.
    - 리소스 매핑과 접근 - 메시지에서 지정한 리소스에 접근한다.
    - 응답 생성 - 응답 헤더를 포함한 HTTP 응답 메시지를 생성한다.
    - 응답 반환 - 응답을 클라이언트에게 돌려준다.
    - 연결 종료 - 로깅
